# הנחיה לסשן Claude Code — סבב 3

להדביק כמו שהיא בהודעה הראשונה של סשן Claude Code (בענן). לבחור את הריפו `idanck/TiviMate-copy` ואת הענף `main`.

---

אני ממשיך את מימוש שפת העיצוב "אולפן" באפליקציית שידור. סבבים 1 ו-2 כבר נמצאים ב-main, וגם תפריט הצד האחד מ-ADR-035.

1. קרא קודם את CLAUDE.md, ואחריו את docs/design/studio/MIGRATION.md, ובעיקר את החלק "סבב 3".
2. מפת הניווט נמצאת בלוח docs/design/studio/canvas/NavMap.dc.html. החצים המקווקווים בה הם החלטות שעוד לא בקוד. המידות והמצבים המדויקים נמצאים במקורות הלוחות, ו-canvas.json מחלק אותם לעמודים.
3. ממש את שלוש ההחלטות שבסעיף 2 של סבב 3. כתוב ADR שמעדכן את ADR-016 לפני שאתה משנה את `stepUpOneOverlay`.
4. לפני שאתה מממש משהו מהסעיף "מה עוד לא בקוד" שאינו אחת משלוש ההחלטות, שאל אותי. אלה שינויי התנהגות ולא רק מראה.
5. אל תיגע בשומר המסך. הוא מחוץ לתכולה.
6. כל שינוי בענף ו-PR נפרדים, עם העלאת versionCode לפי CLAUDE.md. בסוף כל שלב, חכה ל-CI ירוק ועצור לאישור שלי לפני מיזוג ל-main.
