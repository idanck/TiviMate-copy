## האייקון — אייקון מסתגל (adaptive)

**מבנה:** קנבס של 108dp. המשגר חותך את 72dp האמצעיים (מ-18 עד 90) לפי המסכה של המכשיר.

**שכבות:**
- **רקע:** `#FF5A5F` מלא.
- **סימן:**
  - **האות ש (U+05E9):** מהגופן Karantina Bold, שכבר נמצא בריפו ב-`res/font/karantina_bold.ttf`. גודל 64 יחידות, ממורכזת אופקית לפי רוחב ה-advance סביב x=54, וקו הבסיס ב-y=70. צבע `#F3F5F9`.
  - **פס:** מלבן x=38, y=74, רוחב 32, גובה 5, רדיוס פינות 2.5, בצבע `#080C14`.
- **שכבה חד-צבעית** (אנדרואיד 13 ומעלה): האות והפס באותה גיאומטריה, בצבע אחד.

**המרת האות לנתיב:** קובץ וקטורי באנדרואיד לא יכול להשתמש בגופן, ולכן צריך להמיר את האות ש לנתיב (path):
1. לקרוא את קווי המתאר של הגליף מ-`karantina_bold.ttf` (למשל עם `fontTools`).
2. להכפיל בקנה מידה של 64 חלקי `unitsPerEm`.
3. להפוך את ציר ה-Y.
4. להזיז כך שקו הבסיס יהיה ב-y=70 והמרכז ב-x=54.

**קבצים:**
- `mipmap-anydpi-v26/ic_launcher.xml` ו-`ic_launcher_round.xml`, עם רקע, סימן ושכבה חד-צבעית.
- PNG רגילים, למכשירים בלי תמיכה באייקון מסתגל, בגדלים: mdpi 48, hdpi 72, xhdpi 96, xxhdpi 144, xxxhdpi 192.
  - `ic_launcher.png`: ריבוע מעוגל.
  - `ic_launcher_round.png`: עיגול.

  שני הקבצים מצוירים מאותה קומפוזיציה, חתוכה באזור 18 עד 90.

## אריח הטלוויזיה (`android:banner`)

**גודל:** 320×180 פיקסלים בצפיפות xhdpi, כלומר 160×90dp.

**מה עליו:**
- **רקע:** `#FF5A5F` מלא.
- **"שידור":** Karantina Bold, גודל 96, ממורכז סביב x=160, קו בסיס ב-y=118, בצבע `#F3F5F9`. כאן נכתב בכיוון RTL, ואחרי ההמרה לנתיבים הסדר הוויזואלי צריך להיות ש-י-ד-ו-ר מימין לשמאל.
- **פס:** מלבן x=104, y=128, רוחב 112, גובה 7, רדיוס 3.5, בצבע `#080C14`.

**קבצים:** מחליפים את `drawable-xhdpi/tv_banner.png` (320×180) ואת `drawable-mdpi/tv_banner.png` (160×90). אפשר גם לעבור לקובץ וקטורי (`drawable/tv_banner.xml`), כל עוד הוא נראה זהה.

## איך הקבצים נוצרים

`render_icon.py` (באותה תיקייה) קורא את קווי המתאר מ-`karantina_bold.ttf`, מסדר את המילה "שידור" עם HarfBuzz (כמו הדפדפן בקנבס), וכותב:
- `drawable/ic_launcher_foreground.xml` ו-`drawable/ic_launcher_monochrome.xml` (הנתיבים).
- כל קובצי ה-PNG של האייקון והאריח, מרונדרים מאותם נתיבים.

`mipmap-anydpi-v26/*.xml` ו-`values/ic_launcher_background.xml` נכתבו ביד. אחרי שינוי בעיצוב מריצים את הסקריפט מתיקיית השורש (ההוראות בראש הקובץ) ועושים commit למה שהוא כתב.
